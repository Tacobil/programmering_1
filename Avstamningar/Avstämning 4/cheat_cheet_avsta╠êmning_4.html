Programmering 1 - Ruby Cheat Sheet

Utskrift på skärmen (console output)

puts "Hello"   # utskrift med radbrytning
print "Hello"  # utskrift utan radbrytning

Funktionen p skriver ut på ett format som visar utskriftens datatyp (bra vid debugging!):

p "Hello"

Vid utskrift kan variabler integreras i en given sträng genom sträng-interpolering:

age = 18
puts "You are #{age} years old"

Kommentarer i källkod

Inleds med # och kan skrivas efter en kodrad.

sum = a + b   # summera talen a och b

OBS! Om raden inleds med # är hela raden kommentar.

Operatorer för jämförelse

Jämförelse måste ske mellan värden av samma datatyp. En jämförelse utvärderar alltid till true eller false.

Operator Beskrivning
x < y x mindre än y
x > y x större än y
x <= y x mindre än eller lika med y
x >= y x större än eller lika med y
x == y x lika med y
x != y x inte lika med y

If-satser (if-statements)

If-satser har ett eller flera kod-block som utförs om ett villkor är sant. Endast ett block utförs (även om flera villkor är sanna).

# if-elsif-else
if x < y
  z = "smaller"
elsif x > y
  z = "larger"
else
  z = "equal"
end

Iteration med while-loop

En while-loop består av ett villkor och ett kodblock som upprepas (itereras) så länge villkoret är sant.

# Inkrementerande loop
i = 0
while i < 5
  ...
  i += 1
end

Indexering

Enskilda tecken eller värden som ingår i en sträng eller lista/array kallas element. Varje element har ett unikt index (numrerad position). Index är nollbaserat. Index fungerar likadant för strängar och arrayer.

Element B e r t i l
index 0 1 2 3 4 5 
name = "Bertil"
puts name[4]    # "i" skrivs ut

# Speciella index-format:
name[name.length - 1]        # ger sista elementet => "l"
name[name.length - 2]        # ger näst sista     => "i"

Array (lista, fält)

En lista är en datastruktur som innehåller element av en viss datatyp. Listor har många gemensamma egenskaper med strängar, t ex indexering.

my_list = []                        # initiera tom lista
numbers = ["one", "two", "three"]   # skapa lista av strängar
numbers[1]                          # indexering => "two"

numbers << "four"                   # lägg till i slutet
numbers.append("five")              # samma sak

names = ["Katniss", "Peter", "Primrose"]
names.delete_at(1)                  # => ["Katniss", "Primrose"]
names.insert(1, "hej")              # => ["Katniss", "hej", "Primrose"]

numbers = [3, 2, 5, 0, 1, 3, 7]
numbers[1..3]                       # => [2, 5, 0]

Hash (dictionary)

En hash är en datastruktur som lagrar nyckel-värde-par.

# Skapa hash
person = {}                         # tom hash
person = { "name" => "Ada", "age" => 36 }

# Läsa värde
person["name"]                      # => "Ada"

# Uppdatera/lägga till
person["age"] = 37                  # uppdatera
person["city"] = "London"           # lägg till ny nyckel

# Hämta alla nycklar/värden
person.keys                         # => ["name", "age", "city"]
person.values                       # => ["Ada", 37, "London"]

# Kontrollera om nyckel finns
person.has_key?("name")             # => true
person.has_key?("country")          # => false
