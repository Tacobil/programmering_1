== 68. Has Key

`has_key` tar en `Hash` och en nyckel som input och returnerar `true` om nyckeln finns i hashen. Annars returnerar funktionen `false`.

[source, ruby]
.Exempelanrop
----
ages = {"Alice" => 25, "Bob" => 30}
has_key(ages, "Alice") #=> true
has_key(ages, "Charlie") #=> false

empty_hash = {}
has_key(empty_hash, "test") #=> false

prices = {"milk" => 15, "bread" => 25}
has_key(prices, "milk") #=> true
----

====
