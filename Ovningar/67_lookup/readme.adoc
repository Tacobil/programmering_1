== 67. Lookup

`lookup` tar en `Hash` och en nyckel som input och returnerar värdet för den nyckeln. Om nyckeln inte finns i hashen returneras `nil`.

[source, ruby]
.Exempelanrop
----
ages = {"Alice" => 25, "Bob" => 30}
lookup(ages, "Alice") #=> 25
lookup(ages, "Bob") #=> 30
lookup(ages, "Charlie") #=> nil

empty_hash = {}
lookup(empty_hash, "Alice") #=> nil

numbers = {"a" => 1, "b" => 2, "c" => 3}
lookup(numbers, "b") #=> 2
----
