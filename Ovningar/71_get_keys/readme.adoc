== 71. Get Keys

`get_keys` tar en hash som input och returnerar en array med alla nycklar i hashen.

[source, ruby]
.Exempelanrop
----
ages = {"Alice" => 25, "Bob" => 30}
get_keys(ages) #=> ["Alice", "Bob"]

empty_hash = {}
get_keys(empty_hash) #=> []

prices = {"milk" => 15, "bread" => 25, "eggs" => 30}
get_keys(prices) #=> ["milk", "bread", "eggs"]

scores = {"player1" => 100}
get_keys(scores) #=> ["player1"]
----

[IMPORTANT]
====
För att lösa den här uppgiften behöver du kunna använda metoden `.keys` för att hämta alla nycklar från en hash.
====

* Kör de automatiska testerna med `rake` i uppgiftens rotmapp i terminalen.
