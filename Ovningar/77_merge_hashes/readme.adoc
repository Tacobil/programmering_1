== 77. Merge Hashes

`merge_hashes` tar två hashar som input och returnerar en ny hash som kombinerar båda hasharna. Om samma nyckel finns i båda hasharna kommer värdet från den andra hashen att användas.

[source, ruby]
.Exempelanrop
----
hash1 = {"a" => 1, "b" => 2}
hash2 = {"c" => 3, "d" => 4}
merge_hashes(hash1, hash2) #=> {"a" => 1, "b" => 2, "c" => 3, "d" => 4}

first = {"name" => "Alice", "age" => 25}
second = {"city" => "Stockholm"}
merge_hashes(first, second) #=> {"name" => "Alice", "age" => 25, "city" => "Stockholm"}

original = {"a" => 1, "b" => 2}
update = {"a" => 99}
merge_hashes(original, update) #=> {"a" => 99, "b" => 2}
----
